# Emetis App

App mobile React Native / Expo pour [emetis.net](https://emetis.net).

## Stack

- Expo (managed) + Expo Router
- TypeScript strict
- Zustand (state) + TanStack Query (data fetching)
- Jest + React Native Testing Library
- ESLint + Prettier + Husky + commitlint

## Démarrage rapide

```bash
npm install
cp .env.example .env
npm start
```
